Questions before you start

Straight answers about Plotmio.

Can I open an existing Ren’Py project?

Yes. Choose the project root and Plotmio imports the .rpy files inside game.

Do I need an account to try Plotmio?

No account is needed for the interactive demo. Sign in to save your own project or collaborate.

Does Plotmio preserve my exact .rpy formatting?

Export uses normalized formatting. Review generated files before writing them into your project.

Does Plotmio run my Ren’Py game?

Plotmio maps and edits project structure; run and test the game in Ren’Py. Dynamic references and arbitrary Python may remain unresolved.

Which browser do I need to import a local project?

Local folder access currently requires a Chromium browser, such as Chrome or Edge, and your explicit permission.
