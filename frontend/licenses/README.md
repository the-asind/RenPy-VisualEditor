# Supplementary dependency license sources

These files supply license texts missing from the published npm packages.

- `react-codemirror.txt`: MIT, uiw; downloaded from https://raw.githubusercontent.com/uiwjs/react-codemirror/v4.23.10/LICENSE for both @uiw packages at 4.23.10.
- `html-parse-stringify.txt`: MIT, Henrik Joreteg; downloaded from https://raw.githubusercontent.com/henrikjoreteg/html-parse-stringify/master/LICENSE on 2026-09-15. The 3.0.1 package declares MIT; its original commit does not include a standalone license file.

agent-base 6.0.2, https-proxy-agent 5.0.1 and ogl 1.0.11 include complete license texts in their published README files. The generator preserves those texts directly. Update version-specific overrides when upgrading dependencies.
